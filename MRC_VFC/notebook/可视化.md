补一句

val/test 不需要区分 factor，都是固定的
只有 train 需要按 imbalance_factor 切换
所以如果你要看验证集聚类，命令可以直接：

python feature_visualize_vavae.py \
  --run_name 你的stage1_run_name \
  --dataset ISIC2019LT \
  --data_path /data/DataLACP/guyiqin/ISIC2019LT/ISIC_2019_Training_Input \
  --split_dir /data/DataLACP/guyiqin/CODE/Difussion/MRC_VFC/split/ISIC2019LT/shared_eval_seed42 \
  --imbalance_factor 100 \
  --split val \
  --feature_mode mu \
  --methods tsne,umap
这里 imbalance_factor 对 val 路径本身没影响，但我建议仍然带上，保持命令一致。
建议
先看 mu，不要先看 z：

mu 更稳，适合看“类内是否成团/拉长/碎裂”
z 带采样噪声，更适合作对照
如果你想看更完整的分布而不是默认抽样，可以加：

--max_samples_per_class -1 --max_samples_total -1
默认抽样策略
为了让 t-SNE/UMAP 别太慢，脚本默认：

每类最多 300
总共最多 3000
见 feature_visualize_vavae.py (line 186)
